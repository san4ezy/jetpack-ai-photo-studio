# Spec Delta

## MODIFIED Requirements

### Requirement: Interactive Preview Canvas with Before/After Slider and Time Machine Cascade
Полотно перегляду MUST автоматично масштабувати активне зображення (вписувати у доступну область, якщо воно більше за viewport, і показувати у масштабі `1:1`, якщо воно менше за доступну область), підтримувати інтерактивний слайдер «До / Після» без нативного синього виділення при перетягуванні, у режимі `Crop` показувати поверх зображення інтерактивну білу рамку кадрування з напівпрозорим білим затіненням зовні (приховану в інших інструментах, включно з `Resize`), підтримувати центрований перспективний каскад у стилі Apple Time Machine при мульти-виділенні (5–7 передніх карток зі збільшеним вертикальним кроком і відходом назад у темряву), кнопки масштабування (`Zoom Out`, `Fit`, `100%`, `Zoom In`) у правому нижньому кутку полотна та умовне вікно навігації («пошукач» / minimap), розташоване **над** кнопками масштабування. Під час будь-якого масштабування чи прокрутки положення й розмір рамки пошукача MUST точно відповідати тій частині зображення, яку фактично бачить користувач у viewport (зі збереженням фокусної точки при зумі), а сам пошукач MUST завжди використовувати найостанніше оброблене зображення, якщо активний файл має оброблену версію.

#### Scenario: Crop tool displays movable white crop frame with white outer veil over image
- **WHEN** обрано інструмент `Crop` і на полотні відкрито одиночне зображення
- **THEN** поверх зображення відображається біла рамка розміру та співвідношення сторін обраного режиму (центрирована за замовчуванням у межах оригіналу, наприклад `540×540` для `1:1` на `1080×540`), а область поза межами рамки затінюється напівпрозорим білим шаром; користувач може переміщати рамку в межах зображення та змінювати її розмір полями ширини/висоти для точного піксельного кадрування без масштабування (у режимі `Resize` рамка прихована)

#### Scenario: Initial canvas scaling respects image dimensions vs viewport
- **WHEN** на полотні відкривається одиночне зображення або порівняння «До / Після»
- **THEN** зображення займає максимум доступного простору полотна, якщо його натуральні розміри перевищують доступну область, або відображається в оригінальному масштабі 100% (`1:1`), якщо воно менше за доступну область

#### Scenario: Bottom-right zoom controls scale active image and reveal minimap navigator
- **WHEN** користувач натискає кнопки масштабування (`Zoom Out`, `Fit` — розгортання на всю робочу область, `100%` — оригінальний розмір `1:1`, `Zoom In`) або використовує `Ctrl/Cmd + Wheel` над полотном
- **THEN** активне зображення (або контейнер слайдера «До / Після») плавно масштабується зі збереженням поточної фокусної точки (центру видимої області або позиції курсора при колесі миші), і щойно масштабоване зображення перевищує видимі межі полотна, **над** кнопками масштабу з'являється пошукач, який показує мініатюру зображення з рамкою видимої області та дозволяє перетягуванням/кліком точно переміщати область перегляду

#### Scenario: Minimap viewport frame always matches visible image region across zoom and pan
- **WHEN** зображення збільшене (понад межі viewport по горизонталі та/або вертикалі) і користувач масштабує його (`Zoom In`, `Zoom Out`, `100%`, `Ctrl/Cmd + Wheel`), панорамує, змінює розмір вікна або взаємодіє з пошукачем
- **THEN** центр і межі рамки пошукача завжди точно співпадають із фактично видимою користувачем часткою зображення (зокрема, коли користувач бачить центр зображення, рамка пошукача розташована по центру мініатюри, а не зміщена у бік; на краях рамка не виходить за межі мініатюри навіть при мінімальному розмірі рамки, нестандартних співвідношеннях сторін чи наявності скролбарів)

#### Scenario: Minimap navigator always uses latest processed image when available
- **WHEN** активний файл має оброблений результат (включно з повторною обробкою, яка змінює розміри або вміст у `Upscale`, `Crop`, `Resize`, `Enhance`, `Remove BG`, `Blur BG`)
- **THEN** пошукач відображає мініатюру найостаннішого обробленого зображення та обчислює пропорції й рамку видимої області відносно його актуальних вихідних розмірів; після відновлення оригіналу пошукач автоматично перемикається на оригінал

#### Scenario: Single processed image renders interactive Before/After slider
- **WHEN** обрано один файл зі статусом `is_processed = true`
- **THEN** полотно завантажує оригінал та оброблену версію через `studio.get_image` і рендерить рухомий вертикальний розділювач «До / Після» з підтримкою миші/тач-подій, сумісний із поточним масштабом, без артефактів нативного виділення

#### Scenario: Multi-selection renders Apple Time Machine cascade
- **WHEN** у режимі виділення обрано 2 або більше файлів
- **THEN** відображаються до 5–7 передніх карток без зміщення вправо (`translateX = 0`), зі збільшеним вертикальним відступом, зменшенням масштабу та затемненням/зникненням у темряву при відході назад (`translateZ`), із використанням легких прев'ю (`thumbUrl`) для задніх карток та повного перегляду для передньої картки
