# Spec Delta

## MODIFIED Requirements

### Requirement: Top Horizontal Toolbar and Processing Actions
Верхня панель інструментів правої робочої області MUST бути організована вертикально з рядком табів інструментів (`Upscale`, `Enhance`, `Remove BG`, `Blur BG`, `Crop`, `Resize`) зверху та блоком динамічних налаштувань обраного інструменту під табами без жорсткої надлишкової висоти; універсальний глобальний вибір формату `File Type` MUST розміщуватись у Додатковій панелі керування над панеллю інструментів як button group без текстового підпису з кнопками розширень (`AUTO`, `.PNG`, `.JPG`, `.WEBP`), кольори яких збігаються з лейблами типів файлів у Project Folder; а кнопки запуску `Process` і `Process All` MUST бути виконані у виразному зеленому кольорі та розміщені у тонкій Панелі керування над Project Folder разом із кнопкою відкриття робочої папки на ПК.

#### Scenario: Secondary Control Panel hosts color-matched File Type button group without label
- **WHEN** користувач переглядає або перемикає будь-який інструмент обробки
- **THEN** у Додатковій панелі керування над панеллю інструментів відображається універсальна група кнопок вибору формату (`AUTO`, `.PNG`, `.JPG`, `.WEBP`) без підпису `File Type`, де кольори кнопок `.PNG`, `.JPG`, `.WEBP` збігаються з кольорами відповідних лейблів у Project Folder і зберігаються незалежно від обраного інструменту

#### Scenario: Selecting each tool updates dynamic option controls
- **WHEN** користувач перемикає таб інструменту в панелі інструментів
- **THEN** під рядком табів відображаються параметри лише активного інструменту (`2x / 4x` для `Upscale`; статус для `Enhance`; `Transparent / Color` + color picker для `Remove BG`; повзунок `Level` для `Blur BG`; у `Crop` — взаємно виключна група кнопок із `Keep aspect` першим, далі пресети `1:1`, `4:5`, `9:16`, `16:9`, `4:3`, `3:2` і `Custom` останнім; у `Resize` — взаємно виключна група кнопок `Keep aspect` та `Custom`), причому в обох інструментах (`Crop` і `Resize`) компактні поля `<input>` ширини та висоти завжди відображаються в одному рядку з групою кнопок (у `Crop` для всіх режимів крім `Custom` зміна однієї сторони автоматично підганяє іншу під співвідношення в межах активного зображення, а в `Crop: Custom` обидві сторони редагуються незалежно в межах зображення; у `Resize: Keep aspect` зміна однієї сторони пропорційно перераховує іншу, а в `Resize: Custom` обидві сторони редагуються незалежно із дозволеним розтягуванням)

#### Scenario: Process and Process All respect active and selected state
- **WHEN** у режимі `Select` не виділено жодного файлу
- **THEN** зелені кнопки `Process` і `Process All` розміщуються на початку Панелі керування над Project Folder, кнопка `Process All` є неактивною (`disabled`), а кнопка `Process` обробляє поточний активний файл

#### Scenario: Open Folder button in Control Panel opens workspace directory on PC
- **WHEN** користувач натискає кнопку відкриття папки у Панелі керування
- **THEN** фронтенд викликає опкод `studio.open_folder`; якщо системне відкриття виконалось (`opened = true`), папка відкривається у файловому менеджері, а якщо системний sandbox обмежує запуск файлового менеджера (`opened = false`), фронтенд автоматично копіює точний шлях `working_dir` у буфер обміну та показує підказку (`Cmd+Shift+G` у Finder)

### Requirement: Interactive Preview Canvas with Before/After Slider and Time Machine Cascade
Полотно перегляду MUST автоматично масштабувати активне зображення (вписувати у доступну область, якщо воно більше за viewport, і показувати у масштабі `1:1`, якщо воно менше за доступну область), підтримувати інтерактивний слайдер «До / Після» без нативного синього виділення при перетягуванні, у режимі `Crop` показувати поверх зображення інтерактивну білу рамку кадрування з напівпрозорим білим затіненням зовні (приховану в інших інструментах, включно з `Resize`), підтримувати центрований перспективний каскад у стилі Apple Time Machine при мульти-виділенні (5–7 передніх карток зі збільшеним вертикальним кроком і відходом назад у темряву), кнопки масштабування (`Zoom Out`, `Fit`, `100%`, `Zoom In`) у правому нижньому кутку полотна та умовне вікно навігації (minimap), розташоване **над** кнопками масштабування.

#### Scenario: Crop tool displays movable white crop frame with white outer veil over image
- **WHEN** обрано інструмент `Crop` і на полотні відкрито одиночне зображення
- **THEN** поверх зображення відображається біла рамка розміру та співвідношення сторін обраного режиму (центрирована за замовчуванням у межах оригіналу, наприклад `540×540` для `1:1` на `1080×540`), а область поза межами рамки затінюється напівпрозорим білим шаром; користувач може переміщати рамку в межах зображення та змінювати її розмір полями ширини/висоти для точного піксельного кадрування без масштабування (у режимі `Resize` рамка прихована)

#### Scenario: Initial canvas scaling respects image dimensions vs viewport
- **WHEN** на полотні відкривається одиночне зображення або порівняння «До / Після»
- **THEN** зображення займає максимум доступного простору полотна, якщо його натуральні розміри перевищують доступну область, або відобрабражається в оригінальному масштабі 100% (`1:1`), якщо воно менше за доступну область

#### Scenario: Bottom-right zoom controls scale active image and reveal minimap navigator
- **WHEN** користувач натискає кнопки масштабування (`Zoom Out`, `Fit` — розгортання на всю робочу область, `100%` — оригінальний розмір `1:1`, `Zoom In`) у правому нижньому кутку полотна
- **THEN** активне зображення (або контейнер слайдера «До / Після») плавно масштабується (зокрема `Fit` розтягує або стискає зображення на весь доступний простір, а `100%` встановлює точний масштаб `1:1`), і щойно масштабоване зображення перевищує видимі межі полотна, **над** кнопками масштабу з'являється вікно навігації, яке показує мініатюру зображення з рамкою видимої області та дозволяє перетягуванням/кліком переміщати область перегляду

#### Scenario: Single processed image renders interactive Before/After slider
- **WHEN** обрано один файл зі статусом `is_processed = true`
- **THEN** полотно завантажує оригінал та оброблену версію через `studio.get_image` і рендерить рухомий вертикальний розділювач «До / Після» з підтримкою миші/тач-подій, сумісний із поточним масштабом, без артефактів нативного виділення

#### Scenario: Multi-selection renders Apple Time Machine cascade
- **WHEN** у режимі виділення обрано 2 або більше файлів
- **THEN** відображаються до 5–7 передніх карток без зміщення вправо (`translateX = 0`), зі збільшеним вертикальним відступом, зменшенням масштабу та затемненням/зникненням у темряву при відході назад (`translateZ`), із використанням легких прев'ю (`thumbUrl`) для задніх карток та повного перегляду для передньої картки
